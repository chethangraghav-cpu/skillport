# SkillPort

Convert a Claude skill into a skill you can use in ChatGPT. Give SkillPort a source manifest or skill folder. It adapts the instructions, preserves supporting files, and reports which tools or behaviors need manual setup.

For example, a contact-formatting skill can keep its exact output spacing and duplicate handling when moved from Claude to ChatGPT.
